# GenshinWallpaper v0.1.5

- 官方壁纸库新增《光遇 · 向日葵午后》暖阳完整版：向日葵阵风、白蝶、流云与光鳐，1920×1080、30 fps、12 秒循环。
- 设置页根据当前壁纸显示可用控制。光遇保留固定午后光色，可调整亮度、速度、画质及画面比例；魈继续支持昼夜与实时光影。
- 同步网页版的分块缓存修复，改善序列预读和播放流畅度。
- 官方场景、已导入的 MP4 可随时切换；保留用户设置和本地壁纸。
- 安装资源使用已校验的无损独立分块，减少重复完整图集占用；完整原图集继续保存在项目源码中。

Windows x64 / 主显示器。新场景为固定午后网页场景，画面中的风、蝴蝶、云与光鳐随动画播放。
