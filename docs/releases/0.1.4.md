# GenshinWallpaper v0.1.4

- 新增壁纸库，可导入本地 MP4，自动检查画面并生成封面，手动选择后应用到桌面。
- 视频默认静音循环，支持暂停、播放速度、音量、铺满 / 完整画面和时钟设置。切换壁纸释放旧播放器与实时场景。
- 重启、升级后保留本地壁纸和选择。移除只删除软件副本，原始视频保留；失效作品自动回退内置场景并提示。
- 新增维护方录入命令，官方 MP4 随软件版本交付，在壁纸库按来源展示。保留内置魈 / 璃月灯火实时场景与现有 GitHub 更新流程。
- 官方壁纸录入无需作者署名，卡片统一展示壁纸名称、封面和视频信息。

Windows x64，当前使用主显示器。MP4 需要可被内置播放器实际解码，本版本不提供自动转码。

本文件目前用于本地 0.1.4 候选构建；公开发布仍按项目既有流程，附件需要匹配的安装器、blockmap 和 latest.yml。
