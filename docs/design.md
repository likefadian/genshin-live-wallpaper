# 本地桌面阶段设计 · 2026-10-07

目标：在本项目完成可编辑源码与可安装的 Windows x64 动态壁纸软件，直接显示 V3 已验收的魈 / 璃月灯火。用户要求先核对环境、只做必要自查、先看本地效果，后续分阶段扩展独立壁纸包和更新。当前默认主显示器。

Electron 44.6.0（实际 npm 稳定版）+ electron-builder 26.15.3 + NSIS。稳定 appId 为 com.genshinexe.wallpaper，稳定用户目录为 app.getPath('appData')/GenshinEXE。依赖及大缓存留在 D 盘项目内；其他用户选择自己的安装目录。

从 V3 的实际工作区复制渲染器、内容协议、注册配置及必要 JSON，记录来源和哈希；从正式 release/xiao-full-v002/web 复制已接受的 full-v016 图集与场景资源。新项目自身即可重建，不修改 V3。软件只加载内置本地资源，由仅绑定 127.0.0.1 的 HTTP 服务支持 fetch 与 SHA-256 校验。

沿用 varesaEXE 的 Windows Progman/WorkerW 桌面层挂载方法，壁纸位于图标后，鼠标穿透、无任务栏窗口。窗口挂载先于 WebGL 初始化，禁用后台节流。设置窗口只展示控制与静态角色缩略图；经受限 IPC 同步到唯一渲染器，设置由主进程校验并原子保存。托盘提供设置、暂停/恢复、重新连接与退出；设置窗口关闭不影响壁纸，退出释放窗口/服务/定时器。

保留原网页显示与用户参数：晨昼昏夜、跟随本地时间/固定时刻/昼夜预览、亮度/主光/阴影、运动/速度、粒子、灯光、轮廓光、风、Bloom、调色、时间日期、铺满/完整、画质。尺寸、帧数、帧率、焦点和预设读取内容数据。

必要验证：设置存盘与校验、静态资源服务错误处理；实际桌面挂载与短动态观察、设置同步和重启保存、NSIS 安装后的启动/退出。此阶段不做旧角色矩阵或长时间性能测试。

后续范围：外部内容包的协议/兼容与安全安装；真实远程检查/下载/校验/重启升级。当前发布源未配置，界面如实显示“未配置更新源”。构建强制 --publish never；本地版本交付不代表整个远程更新目标完成。
