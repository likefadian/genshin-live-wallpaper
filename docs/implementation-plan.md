# GenshinEXE 本地版本实施计划

**目标：** 交付本地安装版、软件源码，并让用户直接看到真实桌面动画。

**设计：** [design.md](design.md)。在当前空项目中顺序实施；遵循用户对阶段推进和必要自查的要求，合并设计/计划记录，不设置额外流程确认。

**约束：** Windows x64 / 主显示器；V3 full-v016 艺术参数和资源不变；不写入 V3；运行不依赖原 D 盘源目录；不上传、不发布；设置跨启动保存。

- [x] 1. 导入 V3 渲染源、配置与正式资源；生成 catalog.json；加入可独立重建的 prepare-web。
- [x] 2. 设置状态和本地资源服务：先写必要行为测试（保存/坏字段/时间模式、404/路径约束），通过后接入宿主。
- [x] 3. 实现 Windows 桌面窗口、受限 preload、单实例、托盘、轻量恢复和退出；独立设置窗口控制唯一渲染器。
- [x] 4. 必要桌面自查：真实挂载、动作推进、暂停/恢复、设置与重启保存；形成一份简短证据。
- [x] 5. 生成并实际安装 NSIS；确认安装版离开源码路径仍能启动/退出；交付源码 ZIP、安装 EXE、使用说明与哈希。

后续阶段：独立壁纸包安装；用户选定真实更新源后接入 electron-updater 和更新发布清单，并验证真实旧版到新版升级。当前不据此标为完成。
